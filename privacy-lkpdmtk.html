Kebijakan Privasi

Aplikasi Mobile LKPD MATEMATIKA (Android/iOS)

Versi 1.0.3 • Terakhir Diperbarui: 12 Maret 2026

Selamat datang di LKPD MATEMATIKA. Kami menghargai kepercayaan Anda dan berkomitmen untuk melindungi privasi Anda. Dokumen ini menjelaskan bagaimana aplikasi kami beroperasi terkait data pengguna.

1. Pengolahan Data & Konten Lokal

Aplikasi ini menyediakan koleksi Lembar Kerja Peserta Didik (LKPD) yang seluruhnya tersimpan secara lokal (bundled) di dalam aplikasi. Penggunaan konten utama aplikasi tidak memerlukan pengumpulan data pribadi ke server kami.

2. Izin Perangkat & Penggunaan

  • Penyimpanan (Storage): Digunakan saat pengguna menjalankan fungsi Bagikan atau Export PDF untuk memproses file sementara.
  • Akses Internet: Diperlukan untuk memuat layanan iklan pihak ketiga dan sinkronisasi konfigurasi teknis aplikasi.

3. Layanan Iklan Pihak Ketiga

Kami menggunakan layanan Google AdMob untuk menampilkan iklan. Google dapat menggunakan data anonim seperti ID Iklan perangkat untuk menampilkan iklan yang relevan. Kami memastikan kategori iklan tetap aman bagi seluruh pengguna.

4. Keamanan Data

Kami menerapkan standar pengembangan modern menggunakan Expo SDK 54 dengan New Architecture aktif untuk memastikan aplikasi berjalan dengan aman dan stabil pada perangkat Anda.

5. Privasi Anak

Aplikasi ini dirancang untuk siswa SD. Kami tidak secara sengaja mengumpulkan data identitas anak di bawah umur. Kami sangat menyarankan penggunaan tetap di bawah bimbingan orang tua atau guru.
