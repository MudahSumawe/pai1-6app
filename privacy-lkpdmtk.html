Aplikasi LKPD MATEMATIKA

Versi 1.0.3 • Terakhir Diperbarui: 12 Maret 2026

Pernyataan Target Pengguna:
Aplikasi ini dirancang khusus sebagai alat bantu pembelajaran untuk digunakan oleh Guru dan Orang Tua. Aplikasi tidak ditujukan untuk dioperasikan secara mandiri atau langsung oleh siswa/anak-anak di bawah umur tanpa pendampingan orang dewasa.

1. Pengumpulan Informasi

Aplikasi LKPD MATEMATIKA bersifat luring (offline) dan statis. Kami tidak mengumpulkan data identitas pribadi (seperti nama, alamat, atau nomor telepon). Pengguna tidak diwajibkan melakukan pendaftaran akun untuk mengakses seluruh materi LKPD.

2. Izin Perangkat (Permissions)

Aplikasi memerlukan beberapa izin teknis untuk menjalankan fitur utama yang dioperasikan oleh Guru/Orang Tua:

  • Penyimpanan (Storage): Digunakan hanya untuk memproses fitur "Bagikan Gambar" atau "Export PDF" agar file materi bisa disimpan sementara di cache perangkat sebelum dikirim atau dicetak.
  • Akses Internet: Diperlukan untuk memuat layanan iklan pihak ketiga (Google AdMob) dan pembaruan teknis aplikasi.

3. Layanan Iklan Pihak Ketiga

Kami menggunakan layanan iklan untuk menjaga aplikasi ini tetap dapat diakses secara gratis. Penyedia iklan (Google AdMob) dapat menggunakan pengidentifikasi iklan anonim perangkat Anda untuk keperluan teknis dan statistik penyajian iklan sesuai dengan kebijakan privasi Google.

4. Keamanan Data

Semua konten LKPD dibundel langsung di dalam aplikasi. Keamanan data pada fitur ekspor PDF dijamin melalui enkripsi standar sistem operasi Android/iOS yang digunakan oleh perangkat Anda.
